# THE OFFICE 🗣️

Sitio web fan-made dedicado a la serie **The Office (US)**, con perfiles de personajes, sección audiovisual y formulario de contacto.

🔗 **Demo en vivo:** [theofficess.netlify.app](https://theofficess.netlify.app/)

## 📋 Descripción

Proyecto web estático inspirado en la serie de TV *The Office*. Incluye páginas individuales para distintos personajes (Michael, Dwight, Pam, Erin, Toby, etc.) con su información biográfica, relaciones y curiosidades, además de contenido multimedia (imágenes y audios).

## ✨ Características

- Página de inicio con acceso a los personajes principales
- Perfiles individuales de personajes con biografía e información personal
- Sección **Audiovisuales**
- Sección **Formulario** de contacto
- Sección **Contacto**
- Contenido multimedia (imágenes y clips de audio)
- Diseño responsivo

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
